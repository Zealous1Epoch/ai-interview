# AI 面试模拟器 — 产品需求文档 (PRD)

**版本:** v1.0
**日期:** 2026-05-04
**目标用户:** 在校本科生 / 应届生（找实习 / 校招）

---

## 1. 产品定位

为在校生提供一个零成本、随时可用的 AI 面试模拟工具。通过全真模拟发现自身不足，再通过专项练习针对性补强，形成学习闭环。

---

## 2. 用户故事

### 核心流程

- 作为用户，我想在面试前进行一次全真模拟，了解面试流程和节奏
- 作为用户，我希望 AI 面试官能根据我的简历提问，而不是问泛泛的问题
- 作为用户，我希望面试结束后得到具体的反馈，知道哪里做得好、哪里需要改进
- 作为用户，我希望能针对弱项进行专项练习，而不是重新面一遍完整流程
- 作为用户，我希望能回顾之前的所有面试记录，看到自己的进步

### 易用性

- 作为用户，我希望打开网页就能用，不需要注册登录
- 作为用户，我希望面试过程中 AI 能逐字输出，体验像真实聊天
- 作为用户，如果不小心刷新了页面，我希望面试内容不丢失

## 4. 面试流程详情

### 4.1 阶段说明

全真模拟面试共 5 个阶段，AI 自动判断过渡时机：

```
阶段1: 自我介绍
  → AI: "请简单介绍一下你自己"
  → 用户回答
  → AI 根据简历追问 1-2 个相关点
  → 条件满足 → 进入下一阶段

阶段2: 项目深挖
  → AI 从简历中选一个项目深入提问
  → 用户回答
  → AI 可追问技术细节、难点、选型理由
  → 条件满足 → 进入下一阶段

阶段3: 技术问答
  → AI 根据岗位要求出 2-3 个技术问题
  → 每道题用户回答后 AI 可追问或点评
  → 条件满足 → 进入下一阶段

阶段4: 行为问题
  → AI 出 1-2 个行为问题（STAR 方向）
  → 用户回答后 AI 可追问细节
  → 条件满足 → 进入下一阶段

阶段5: 反问环节
  → AI: "你有什么想问我的吗？"
  → 用户提问，AI 以面试官视角回答
  → 用户没有更多问题 → 结束面试
```

### 4.2 面试结束条件

- 所有阶段完成 → 正常结束
- 用户主动点击"结束面试"
- 超过 10 分钟无响应 → 自动结束

## 5. 评估报告

### 5.1 评分维度

| 维度 | 说明 |
|------|------|
| 技术能力 | 基础知识掌握程度 |
| 沟通表达 | 回答是否清晰、有条理 |
| 逻辑思维 | 分析问题的逻辑性 |
| 项目经验 | 项目理解和深度 |

评分方式：1-10 分，AI 自动评分。

### 5.2 报告内容

- 总体评分（星级）
- 各维度评分（进度条）
- 综合评价（一段文字）
- 优势列表
- 待改进列表（每项可点击进入专项练习）
- 面试对话回顾（可展开）

---

## 6. 专项练习模式

### 6.1 入口

评估报告页的待改进项旁，点击"专项练习"进入。

### 6.2 支持类型

| 类型 | 行为 |
|------|------|
| 八股文 — 计算机网络 | AI 出网络相关八股题，答完给参考答案 |
| 八股文 — 操作系统 | AI 出 OS 相关八股题 |
| 八股文 — 数据库 | AI 出数据库相关八股题 |
| 八股文 — 编程语言 | AI 出语言相关八股题 |
| 行为问题 | AI 出行为题，提示 STAR 结构 |
| 项目深挖 | AI 模拟面试官深挖项目细节 |

### 6.3 交互方式

- AI 连续出题
- 用户回答后 AI 给出参考答案和点评
- 可设置练习数量（如 5 题）
- 可随时退出

---

## 7. 数据存储

| 数据 | 存储方式 | 说明 |
|------|---------|------|
| 面试设置 | 无持久化 | 每次面试前填写 |
| 面试对话 | IndexedDB | 完整对话记录 |
| 评估报告 | IndexedDB | 评分和反馈 |
| 面试状态 | sessionStorage | 防止刷新丢失 |
| API Key | 服务端 `.env.local` | 开发者提供 |

无用户注册系统。数据全部存储在用户浏览器本地。

---

## 8. 非功能需求

| 需求 | 要求 |
|------|------|
| 加载性能 | 首屏加载 < 3s |
| AI 响应 | 首字符显示 < 3s（流式） |
| 兼容性 | 现代浏览器（Chrome / Edge / Safari 最新版） |
| 部署 | 支持 Vercel 一键部署 |
| 安全性 | API Key 仅存服务端，不暴露给前端 |

## 10. 约束与局限

- 不支持用户注册 / 跨设备同步
- 算法题练习首版不做（涉及代码执行环境）
- 不支持音频输入（纯文字交互）
