# AI 面试模拟器 - 设计文档

## 概述

面向在校本科生/应届生的 AI 面试模拟 Web 应用。用户可以进行全真模拟面试，结束后获得评估报告，并针对弱项进行专项练习。

## 技术栈

| 层面 | 技术 |
|------|------|
| 框架 | Next.js 14+ (App Router) |
| 样式 | Tailwind CSS |
| 状态管理 | Zustand |
| 本地存储 | IndexedDB (via `idb`) |
| AI API | DeepSeek (通过 Anthropic 兼容接口) |

## 用户流程

```
首页 → 面试设置（填写岗位/简历/方向）→ 全真模拟面试 → 评估报告 → 专项练习 → 再来一次
                                                              ↑_________________↓
```

无用户注册，所有数据存储在浏览器 IndexedDB 中。

## 页面结构

| 页面 | 路由 | 功能 |
|------|------|------|
| 首页 | `/` | 欢迎页，进入设置或查看历史 |
| 面试设置 | `/setup` | 填写目标岗位、简历内容，选择面试方向 |
| 面试中 | `/interview` | AI 面试对话界面，流式输出 |
| 评估报告 | `/report/[id]` | 多维度评分与反馈，入口进入专项练习 |
| 历史记录 | `/history` | 查看所有历史面试和报告 |

## 面试流程（状态机）

全真模拟面试按以下阶段依次推进，AI 根据用户回答自然过渡：

1. **自我介绍** — AI 引导用户自我介绍，根据简历追问 1-2 个点
2. **项目深挖** — 选择简历中一个项目深入提问
3. **技术问答** — 根据岗位要求穿插 2-3 个技术问题（八股文方向）
4. **行为问题** — 1-2 个行为问题（STAR 方向）
5. **反问环节** — 邀请用户提问
6. **结束** — 触发评估报告生成

阶段切换由 AI 在每一轮回答后判断是否该自然过渡。

## AI 面试官引擎

### Prompt 分层结构

**第 1 层 — 角色设定（固定）：**
你是一位温和但有深度的技术面试官，面向在校生/应届生，不故意刁难但会追问。每次只问一个问题，使用中文交流。

**第 2 层 — 面试上下文（每次请求携带）：**
- 目标岗位
- 简历摘要
- 当前阶段
- 历史对话摘要（控制 token 消耗）
- 已问过的问题列表（避免重复）

**第 3 层 — 阶段指令（随阶段切换）：**
每个阶段有特定的提问策略和过渡条件。

**第 4 层 — 评估指令（面试结束时触发）：**
生成结构化评估，包含各维度评分和改进建议。

### API 调用

- 面试中：`stream: true`，前端逐块渲染
- 评估生成：面试结束后单独请求，非流式

## 专项练习模式

入口在评估报告页面，针对弱项进行针对性练习。

- 无完整面试流程，只聚焦一个环节
- AI 连续出题，用户答完后 AI 给出参考答案和点评
- 支持题型：八股文（细分学科）、行为问题、项目深挖
- 算法题：暂不实现

## 存储结构（IndexedDB）

### interviews 表
- `id`, `createdAt`, `position`, `direction`, `resume`
- `messages[]` — 完整对话记录
- `duration` — 面试时长

### reports 表
- `id`, `interviewId`
- `scores` — { technical, communication, logic, project }
- `summary`, `strengths[]`, `improvements[]`, `suggestions[]`

## 边界情况

| 场景 | 处理 |
|------|------|
| AI 响应超时（>30s） | 提示重试 |
| 网络断开 | 提示用户，保留对话 |
| 长时间不回答（5min） | 提示"还在吗？" |
| 刷新页面 | sessionStorage 恢复状态 |
| 回答过短 | 提示"能多说一些吗？" |
| IndexedDB 满 | 提示清理旧记录 |

## 非功能性需求

- AI API Key 配置在服务端 `.env.local`（开发者提供）
- 无数据库依赖，部署简单（Vercel）
- 响应速度快，流式渲染体验
